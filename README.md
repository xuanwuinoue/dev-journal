# 📓 dev-journal

One entry per day of what I learned or built. Every day is a commit.

> Rule: **small counts.** 15 real minutes beat zero.

## How it works

1. Run `./new-day.sh` (or `.\new-day.ps1` on Windows) → creates today's file at `days/YYYY/MM/YYYY-MM-DD.md`.
2. Write what I did, with code if there is any.
3. `git add . && git commit -m "day: YYYY-MM-DD - <topic>" && git push`

## Ideas for days with no ideas

- Solve 1 exercise (LeetCode, Beecrowd, Exercism) and save the solution here
- Explain a concept from college in my own words
- 5 new Japanese words/kanji plus a tiny program that uses them
- One small improvement to a game (a bug, a sound, a menu)
- A "TIL" (Today I Learned): something I didn't know yesterday
